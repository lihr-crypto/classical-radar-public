# ADR-0007 — 海外乐团来日线索：用オケミン！，但不当官方数据

日期：2026-11-12。状态：采纳。**2026-11-17 起“手动读取、随 PR 审阅、不做定时刷新”这几条被 [ADR-0018](0018-tour-leads-in-the-daily-run.md) 取代：线索也由每日云端任务读取并自动上线（其余——只当线索、标“未核实”、官方优先——不变）。**2026-11-20 起发现页栏目标题去掉括号里的“第三方整理，未核实”，只写“海外乐团来日”（用户说副标题不需要；虚线框和每张卡片上的“未核实”标记保留，`#leads` 页顶部和详情页底部的说明句也保留）；书架里的卡片统一高度、文字过长时截断，同月日期写成“11月20日 – 23日”。**起因：用户说“オケミン！里的信息也可以用”（海外乐团的数据太少，当时线上只有 15 场、12 个乐团，全部来自 Japan Arts / KAJIMOTO / 神奈川艺术协会）。

## 来源情况（实测，证据见 [evidence/leads/okemin-2026-11-12.json](../../evidence/leads/okemin-2026-11-12.json)）

| 项 | 事实 |
|---|---|
| 性质 | 个人运营的“海外乐团来日公演”整理站，不是官方，也不是主办方；页面有广告和作者个人评分 |
| 内容 | 年度汇总页（2026、2027）：每个乐团的期间、会场（城市）、指挥、独奏；每个乐团一篇文章：每场的日期、开演时间、会场、曲目。**没有主办方、没有官方链接、没有售票链接** |
| robots.txt | 只禁止 `/wp-admin/`（admin-ajax 除外）和一个插件 JSON，没有 Crawl-delay |
| 使用条款 | 没有找到转载/复用条款；页脚版权声明“© 2023-2026 オケミン！”；页面写明信息来自杂志《音乐の友》和读者提供，不是官方公告 |
| policy_status | `unknown`（和其他来源一样，启用不改变政策状态，ADR-0001） |

`02_SOURCES.md` 原先把它列为“只做线索、不是默认授权的官方正文抓取源”。用户明确决定可以用，所以按“线索”用：**可见、可查、可点回原文，但绝不当作官方确认的数据**。

## 决定

| 问题 | 决定 |
|---|---|
| 放进哪里 | 单独的表 `tour_lead`（不在 03_CONTRACTS，和 `duplicate_review` 一样是扩展）。**不进 `concert`/`performance`**：不会出现在发现页、日历、搜索、提醒、监测、重复复核里，也不能被 `confirm_stored` 当成官方确认。线索 id（`lead-…`）永远不会被当成节目 id |
| 存什么 | 只存事实：乐团、日期、城市、指挥、独奏、会场、曲目行。不存页面文字、图片、作者评分。每张卡和详情页都有来源署名“オケミン！”和原文链接 |
| 怎么读 | `classical-radar leads-sync`（手动，没有定时器）：先读并遵守 robots.txt；间隔 2 秒；一次最多 80 个请求；只读 okemin.com，不带 cookie，跳转到别的站点就拒绝；401/403/429 立即停止，不重试；3 天内读过的文章在列表没变时不再读 |
| 日期 | 页面写了几号才存几号；只写了月份的存成“某年某月（具体日期未定）”；跨年的期间自动推年；解析不了的场次直接跳过，不猜 |
| 谁算线索 | 只取“オーケストラ”标题下的块；“リサイタル”下的独奏家不算 |
| 官方已有怎么办 | 同一乐团（按乐团表识别）、有一场官方确认的演出落在线索的日期范围（前后各 1 天；只有月份的按整月）内 → 这条线索标为“已有官方信息”，在发现页的线索栏里隐藏，在线索列表里单独列出并链到官方卡。**官方优先** |
| 消失的线索 | 最近一次读取没再看到的线索不再显示（不会永远留着）；已过日期的线索不显示 |
| 线上站点 | 线上没有数据库：`leads-export` 写 `site-data/leads.json`（随 PR 审阅，和 concerts.json 一样）；`build_site.py` 校验后写入 `site/data/leads.json`（在登录后面，和 concerts.json 同样的头）；“已有官方信息”在构建时对照当时发布的官方数据算出。免登录的只有 `/icons/*` |
| 界面 | 发现页多一栏“海外乐团来日”（2026-11-20 前标题后面带“（第三方整理，未核实）”）：虚线框的卡片（不是填色封面），带“未核实”标记；`#leads` 列表页；`#lead/<id>` 详情页（顶部说明、各场次的日期/时间/会场/曲目、原文链接）。线索只在这两处出现，不混进官方列表 |
| 乐团表 | 新增页面里出现、表里没有的 27 个海外乐团（含中文名），所以筛选和标签认得它们 |

## 没做 / 已知限制

- 线索不进日历和搜索（要的话再说）；不解析售票日；没有主办方信息（页面没有）；不做定时刷新。
- 2026 年的整理里很多已经结束，只显示还没过去的。
- 页面只写“东京、名古屋 他”时，城市列表是不完整的，卡片上显示“等”。
- 站点是个人博客，信息可能错、可能改：这就是“未核实”的含义；以后某个乐团出现官方来源，线索自动让位给官方数据。
- 公开快照不含抓取的数据（`concerts.json`、曲目行等）；自行部署时数据由你自己抓取。
- 一次真实读取：45 个请求，52 条线索（2026 年页 26 个块、2027 年页 26 个块），全部识别出乐团，38 条有分场次信息，14 条只有列表层信息；构建时 6 条已被官方数据覆盖。
