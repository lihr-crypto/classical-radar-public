# 界面设计方向

2026-11-05。`src/classical_radar/web/` 的界面按这份方向做；样式和脚本的文件头都指向这里，`tests/test_ui.py` 的 `DesignRuleTests` 和 `tests/js/cover.test.mjs` 把其中能机械检查的规则写成了测试。

方向来自你给的设计原型（一个 Vue 页面，用内存路由和自己的数据投影做成）。这里把它的视觉和信息结构搬到现有的无构建原生 JS 界面上，数据层、接口和全部功能不变。早先那版（纸色、靛蓝、衬线标题、无封面）被它取代；那一版的方法记录在提交历史里。

## 方向

- **产品**：个人用的日本古典音乐会追踪器，汇总官方已公布的演出和开票时间，让一个人看清接下来有什么、票何时开、自己打算去哪场。
- **性格**：明快、清楚、手机优先。
- **世界**：演出海报和节目册的色块：白底、黑字、整块的颜色，大号窄体数字和日文标题。
- **亮点**：按类型着色的封面方块（主办方公演灰蓝、钢琴独奏灰紫、乐团灰绿，2026-11-11 起全部低饱和）；赭金标“开票”，也做块标题前的小竖条；发现页的横向书架。（详情页顶部的整块色在 2026-11-17 去掉了，见 ADR-0011。）
- **图标与品牌**（2026-11-11）：五根管风琴、中间一根赭金，下写小写 classical / radar（Futura 粗体）；石板蓝 #2e3442、雾白 #e6e4df、赭金 #b8955a。界面配色和数字字体跟随它。图标文件由 `scripts/build_icons.py` 生成。
- **标志**：诚实的空白。时刻未知写“时间未公布”或画成 `––:––`，永远不猜；封面上的字只取自已有数据，取不到就退回主办方代码。

## 结构

- 手机：底部四个标签（发现 / 日历 / Pickup / 搜索）。桌面（≥960px）：左侧栏，同一个导航元素。本地应用多一个“待确认”标签；网页版和 demo 没有。
- 发现：12 / 24 个月（2026-11-17 去掉了“首都圈 / 全国”和“搜索与筛选”，范围固定为首都圈，ADR-0011）；书架“主办方公演”（一张大卡加横滑）、“钢琴独奏会”；“东京乐团”（乐团按钮加列表行）。每个书架的“全部 N”进入 `#list/<类型>`。
- 搜索：一个搜索框（作品、作曲家、演奏者、乐团、场馆，也认乐团的中英文名）、一行类别；选“东京乐团”时多出一行乐团小标签（与上一行隔开：间距、细线、“乐团”小标签、小号芯片，ADR-0012）。2026-11-17 去掉了提示语、第二个乐团搜索框、“更多乐团”和结构化筛选（按人物与曲目浏览已覆盖，ADR-0011）。
- Pickup：三块，预定前往（打算去的节目）、Pickup（想看的节目）、已结束（两者里已结束的，同一场只出现一次）。每场的状态（想去 / 已购票 / 已观演…）仍在详情页的日程卡里（ADR-0012）。
- 日历：大号月份，“演出日 / 开票日”，一行乐团筛选（全部乐团加七个乐团，2026-11-17 起没有搜索框和“更多乐团”，ADR-0012），日期网格，点日期在下面列当天。日期下面的小字是当天场数（“3场”；开票日模式下是“3项”开票节点），当天有 Pickup 的演出时变蓝加粗；没有圆点（2026-11-20 去掉：圆点最多画三个，一天 8 场和 3 场看起来一样，意思也没人看得懂）。换月有四种方式：上个月 / 下个月箭头、网格上左右滑动（触屏，从屏幕边缘开始的不算，那是浏览器自己的后退手势）、点月份名弹出选月面板（年份加十二个月）、“今天”按钮一键回当月（当月时灰掉）。整页 `touch-action: manipulation`，快速连点不会触发双击放大，连点按“当下所在的月”累加。
- 详情：独立页面 `#concert/<id>`（不再是弹层），所以浏览器的后退、分享链接都能用；冷启动直接进详情时“返回”回到发现。2026-11-17 起是紧凑排版：圆形返回 / 分享、类别小标签、标题、乐团行、曲目 / 出演 / 日程三块、两个大按钮（加入 Pickup、预定前往；官网退成下面一行，ADR-0012），不再有整块色封面。曲目、人物页（`#browse/<种类>/<id>`）同款顶栏，加“找音源”（Apple Music Classical 里这位 / 这首的**本人页面**，id 来自审过的对照表，表里没有就不显示按钮，ADR-0013）和演出卡片。
- 来源：`#sources`，从发现和搜索页底部的链接进入。

## 封面

封面是装饰，由规则从已有字段生成，规则在 `app.js` 的 `<cover-rules>` 块里，`tests/js/cover.test.mjs` 在全部 456 个节目上执行它。

| 类型 | 条件 | 大字（按顺序取第一个） |
|---|---|---|
| 钢琴独奏 | `category = piano_recital` | 第一位出演者的姓（外国人名取最后一段）→ 主办方代码 |
| 乐团 | 来源是东京乐团之一 | 标题里的“第 N 回”→ 《》「」里的曲名（≤14 字）→ 乐团代码（NHKSO、TMSO…） |
| 主办方公演 | 其余 | 《》「」里的曲名 → 标题里出现的指挥或独奏者的姓 → 主办方代码 |

- 署名（封面左上）：主办方名；乐团封面用简称。来源未知时署名和大字都留空，不编。
- 放不下就退回主办方代码，不用省略号，因为被截断的曲名看着像数据。小方块（56px）更严：只容 4.5 个字宽，放不下的钩子改用代码。
- 封面对读屏软件隐藏，标题才是卡片的名字。
- 有授权照片时用照片做封面（目前 456 个节目里是 0 个）。
- 主办方名只在一处定义（`ORG`），封面署名、来源表和待确认列表共用。
- 数据：发现列表、日历、Pickup 的条目都带 `organization_id`（见 03_CONTRACTS），封面据此分类。

## 规则

| 项 | 规则 |
|---|---|
| 颜色 | 灰白底（#f5f5f3）石板墨字（2026-11-11 前为纯白底）；三层文字（墨 / 次要 / 更淡）；三种封面色；赭金只做背景、配深色字，不做文字色；语义色 ok / warn / bad；没有渐变、发光 |
| 对比度 | 所有文字与底色的组合在亮色、系统深色、手动深色三套里都 ≥ 4.5:1，由测试守住；两个深色块必须一致 |
| 字体 | Futura（苹果设备自带，图标所用）用于数字、英文、月份与日期大字；其他系统回退到自托管的 Archivo。封面大字和日历小方块仍用窄体 Archivo，因为封面字号规则按它的宽度调过，换宽字会被截断；中日文走系统字体（苹方、冬青黑体、微软雅黑、Noto）；日文内容标 `lang="ja"` |
| 字重 | 400–900；封面和大数字用 800–900 加 62% 窄体 |
| 字距 | 不用负字距，不用大写加字距，不用斜体 |
| 圆角 | 封面 12，小方块 8，控件 12，胶囊 999 |
| 图标 | 内联 SVG 线性图标，1.5 描边，用 `document.createElementNS` 画，不解析字符串，不用文字符号 |
| 日期 | 日本时间；当年省略年份；时间戳带 `JST`；界面里不出现 ISO 日期 |
| 动效 | 只有颜色过渡，150ms，同一条缓动；尊重 `prefers-reduced-motion` |
| 可访问性 | 整张卡是一个链接（一个 Tab 停靠点）；进入详情页标题拿焦点，返回时回到同一张卡并恢复滚动位置；当前标签有 `aria-current`；状态按钮用 `aria-pressed` |

## 取舍

- **找回了生成封面。** 上一版因为“456 个节目里 0 个有授权照片、渐变方块只取第一个字”去掉了它。这一版的封面不用渐变，大字是有内容的（期数、曲名、姓名），取不到时诚实退回主办方代码；这是你选的方向。
- **加了一个接口字段。** `organization_id` 进了发现、日历、Pickup 三处列表（可空，增量）。它在详情里本来就有。
- **按类型分组在浏览器里做。** 接口没有“类型”过滤（类型是界面概念），所以发现页把当前时间范围的所有页拉下来（每页 100 条，并行），分组后缓存。456 个节目时是 5 个请求。
- **个人状态只能切换，不能清除。** 接口没有清除状态的入口，和上一版相同。三个常用状态（想去 / 已购票 / 已观演）是按钮。（2026-11-19，ADR-0019：原来还有一个“其他状态”菜单放计划购票 / 已申请 / 已中签 / 放弃，已去掉；接口照旧接受这四个值，已经保存的在 Pickup 页还是原样显示。）
- **提醒只给还没开始、有精确时刻的开售阶段。** 日期不精确的显示禁用的“无精确时刻”。**提醒目前只做记录，不会发通知**（ADR-0002）：按钮写“记下提醒 / 已记下提醒（暂不发送）”，“售票”标题下有一行说明，点击后的提示条也说明；真正接上发送之前不要改回“提醒我”（`tests/test_ui.py` 会拦）。
- **去掉了原型里没有数据的部分**：“已官宣，日期未定”和“未核实消息”两个列表，以及“候选，尚未人工核对”的措辞；我们的节目都是官方确认的。
- **改了一个颜色**：`--faint` 从 `#7a7d86` 改成 `#6b6e77`（4.11:1 → 5.09:1），为了通过 4.5:1。

## 没有验证的

只在无头 Chromium 和应用内浏览器里看过，没有在真机 Safari、Windows、Android 上看过；200% 缩放没有测。日文字重 900 依赖系统字体（苹果设备上是冬青黑体 W9），其他系统会回退到各自的粗体。冷启动深链接在 Cloudflare Pages 上还没有实测。
