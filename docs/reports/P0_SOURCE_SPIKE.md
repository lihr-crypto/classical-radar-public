## 实测范围

十个官方列表入口均返回 HTTP 200。九站 robots 返回 200，东京爱乐 robots 返回 404；当前读取路径未被取得的 robots 排除。缺 robots 或允许路径均不代表获得自动采集/再发布许可。十站均未启用定时任务。

本机通过 `httpx` 获取实际响应；八站静态列表解析、NHK 公共 JSON 解析和读卖两个详情解析有可回放事实片段。未使用浏览器渲染、LLM、付费接口或登录。

## 政策检查与降级

`evidence/probe.json` 保存 robots 原文、HTTP、哈希、时间、同域使用条件链接。除都响明确的使用条件外，其他站点本轮主要检查到版权声明或隐私条款，没有取得可供定时采集/公开再发布的肯定授权。**政策状态仍为 unknown，不能写 permitted。** 东京爱乐 robots 缺失单独记录。KAJIMOTO 明确禁止复用其图片，本项目没有抓取/提交图片。

都响后续优先使用官方链接索引、人工确认或许可途径；其他来源先复核站点使用条件和所需使用范围，再决定是否开启定时更新。源码仅提交日期、地点、标题等必要事实片段，全文响应保持本地。这里记录工程检查事实，不把 robots 当法律结论。

## 测试与验收边界

- 13 项 `unittest` 测试通过，其中事实片段回放包含 14 份 HTML fragment、26 场记录；另有 NHK 同节目双场次 JSON。快照预期只是回归基线，不是独立准确率统计。
- 有独立断言检查 NHK 两场准确日期/时间、KAJIMOTO 一般销售时间、会员与一般阶段分离、空值、时区、开场/开演区分、归档排除、去重和内容差异。
- 网络测试用模拟响应验证 401/403/429 停源和重定向重新校验；本轮真实网络没有遭遇限流，**未证明真实故障恢复或长期稳定性**。
- Python 3.14.7、锁定依赖安装、`pip check`、离线 CLI 实测；没有数据库、API、UI、邮件、iPhone 或生产部署验收。

## Gate 结论和待完成项

**GO：继续数据验证与统一契约准备。NO-GO：正式自动提醒/公开完整网站。** 原因与最小后续工作如下。

1. 对照原始 V1.5 `03_CONTRACTS.md`；若仍无法取得，明确记录后再冻结本项目统一字段，禁止把本 POC 结构直接称原版契约。
2. 补读卖未来月份枚举，展开东京爱乐多日期，检查各站分页/月份与远期。为每个来源建立有 URL 清单的独立官方基准 N，报真实 `n/N` 与缺漏原因。
3. 对 Japan Arts/KAJIMOTO 全部已发现 UPCOMING 项目及新增钢琴独奏会进行详情对照，补互补来源；不要因为一个主办方抓取成功就声称覆盖日本所有来日公演。
4. 核对来源使用条件；在适当的许可访问范围内补两次及更长期的实际监测，测量新公告/改期发现延迟。目前只有单轮快照。
5. 实现售票公告与具体场次/渠道关联、特殊会期排除、精度和取消/改期规则，再考虑通知。
6. 验证上述门槛后才开始 P1 数据库/API。保留 URL 确认导入备用路径；本轮没有实现 URL 导入 UI 或持久化。
